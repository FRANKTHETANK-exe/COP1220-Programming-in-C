# COP1220 Programming in C

My C assignments for this class. Each `.c` file is a separate program. They include hurricane categories, perfect numbers, a Caesar cipher, Pig Latin, and sales summaries.

## Running an assignment

Compile the file you want to run, then start the program. For example:

```sh
cc "assignment 6-2.c" -o caesar
./caesar
```
